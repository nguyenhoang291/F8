Todo List là một ứng dụng nhỏ nhưng rất phù hợp để người mới học lập trình web luyện tập các kiến thức cơ bản như HTML, CSS, JavaScript, DOM và xử lý sự kiện. Trong bài viết này, chúng ta sẽ xây dựng một ứng dụng Todo List đơn giản với 3 chức năng chính:

  1. Thêm công việc
  2. Hiển thị danh sách công việc
  3. Xóa công việc

Ứng dụng sẽ được xây dựng hoàn toàn bằng HTML, CSS và JavaScript, không sử dụng thư viện bên ngoài.

1. Chuẩn bị cấu trúc project

Đầu tiên, hãy tạo một thư mục có tên `todo-list`. Bên trong thư mục tạo 3 file:

        todo-list/
        │
        ├── index.html
        ├── style.css
        └── script.js

Trong đó:

  1. index.html: Xây dựng giao diện
  2. style.css: Thiết kế giao diện
  3. script.js: Xử lý chức năng Todo List.

Việc tách thành 3 file giúp project dễ quản lý và cũng là cách tổ chức phổ biến khi học HTML, CSS và JavaScript.

2. Xây dựng giao diện HTML

Trước tiên, chúng ta sẽ tạo phần giao diện cơ bản. Giao diện sẽ gồm:

  1. Tiêu đề Todo List.
  2. Ô nhập công việc
  3. Nút Thêm
  4. Danh sách các công việc

Mở file index.html và thêm đoạn code sau:

        
            <!DOCTYPE html>
            <html lang="vi">
            <head>
                <meta charset="UTF-8">
                <meta name="viewport" content="width=device-width, initial-scale=1.0">

                <title>Todo List</title>

                <link rel="stylesheet" href="style.css">
            </head>
            <body>

                <div class="todo-container">
                    <h1>Todo List</h1>

                    <div class="todo-input">
                        <
                            input
                            type="text"
                            id="todoInput"
                            placeholder="Nhập công việc..."
                        >

                        <button id="addButton">Thêm</button>
                    </div>

                    <ul id="todoList"></ul>
                </div>

                <script src="script.js"></script>
            </body>
            </html>

Giải thích

Phần input dùng để người dùng nhập nội dung công việc.

        
            <
                input
                type="text"
                id="todoInput"
                placeholder="Nhập công việc..."
            >

Chúng ta đặt id="todoInput" để JavaScript có thể tìm và lấy nội dung mà người dùng nhập.

Nút: <button id="addButton">Thêm</button> sẽ được sử dụng để kích hoạt chức năng thêm công việc.

Cuối cùng: <ul id="todoList"></ul> là nơi JavaScript sẽ tạo và hiển thị danh sách công việc.

giúp nội dung công việc nằm bên trái và nút xóa nằm bên phải.

4. Lấy các phần tử HTML bằng JavaScript

Bây giờ chúng ta bắt đầu xử lý logic của ứng dụng. Mở file script.js. Đầu tiên, chúng ta cần lấy các phần tử HTML mà JavaScript sẽ thao tác. Thêm đoạn code:

        
            const todoInput = document.getElementById("todoInput");
            const addButton = document.getElementById("addButton");
            const todoList = document.getElementById("todoList");

Giải thích

document.getElementById() cho phép JavaScript tìm một phần tử HTML thông qua id.

Ví dụ: const todoInput = document.getElementById("todoInput"); JavaScript sẽ tìm: <input id="todoInput"> và lưu phần tử đó vào biến todoInput. Tương tự:

  • addButton: nút Thêm
  • todoList: danh sách công việc

5. Xây dựng chức năng thêm công việc

Đây là chức năng quan trọng đầu tiên. Khi người dùng nhập: Học JavaScript và nhấn nút Thêm, công việc này sẽ xuất hiện trong danh sách. Thêm đoạn code sau vào script.js:

        
            addButton.addEventListener("click", function () {

                const todoText = todoInput.value.trim();

                if (todoText === "") {
                    alert("Vui lòng nhập công việc!");
                    return;
                }

                const todoItem = document.createElement("li");

                todoItem.classList.add("todo-item");

                todoItem.innerHTML = 
                `     
                    <span>${todoText}</span>
                    <button class="delete-button">Xóa</button>
                `;

                todoList.appendChild(todoItem);

                todoInput.value = "";
            });

Giải thích

Đầu tiên: addButton.addEventListener("click", function () {}) chúng ta yêu cầu JavaScript lắng nghe sự kiện click trên nút Thêm. Khi người dùng click vào nút, đoạn code bên trong hàm sẽ được thực hiện.

Tiếp theo: const todoText = todoInput.value.trim(); todoInput.value lấy nội dung người dùng nhập.

Ví dụ người dùng nhập: Học HTML

Thì: todoInput.value sẽ có giá trị: Học HTML và trim() giúp loại bỏ khoảng trắng thừa ở đầu và cuối chuỗi. Sau đó kiểm tra người dùng có nhập nội dung hay chưa:

if (todoText === "") { alert("Vui lòng nhập công việc!"); return; }

Nếu ô nhập trống, chương trình hiển thị thông báo và dừng lại. Tiếp theo, chúng ta tạo một phần tử <li> mới:

const todoItem = document.createElement("li");

Sau đó thêm class CSS: todoItem.classList.add("todo-item");

Cuối cùng tạo nội dung cho công việc: 

            
                todoItem.innerHTML = 
                `
                    <span>${todoText}</span>
                    <button class="delete-button">Xóa</button>
                `;

Mỗi công việc sẽ có dạng:

        
            <li>
                <span>Học JavaScript</span>
                <button>Xóa</button>
            </li>

Sau đó: todoList.appendChild(todoItem); đưa công việc mới vào danh sách. Cuối cùng: todoInput.value = ""; xóa nội dung trong ô nhập để người dùng có thể nhập công việc tiếp theo.

6. Xây dựng chức năng xóa công việc

Hiện tại chúng ta đã có thể thêm công việc nhưng nút Xóa chưa hoạt động. Chúng ta sẽ sử dụng sự kiện click để xác định nút Xóa được nhấn và xóa công việc tương ứng. Thêm đoạn code sau vào script.js:

        
            todoList.addEventListener("click", function (event) {

            if (event.target.classList.contains("delete-button")) {

                const todoItem = event.target.parentElement;

                todoItem.remove();
            }
        });

Giải thích

Thay vì tạo sự kiện cho từng nút Xóa, chúng ta đặt một sự kiện trên toàn bộ danh sách:

todoList.addEventListener("click", function (event) {

Khi người dùng click vào bất kỳ vị trí nào trong danh sách, JavaScript sẽ kiểm tra phần tử được click. event.target chính là phần tử mà người dùng vừa click. Chúng ta kiểm tra: event.target.classList.contains("delete-button")

Nếu phần tử được click có class delete-button, nghĩa là người dùng vừa nhấn nút Xóa. Sau đó:

const todoItem = event.target.parentElement; lấy phần tử <li> chứa nút Xóa. Ví dụ: 

            
                <li class="todo-item">
                    <span>Học JavaScript</span>
                    <button class="delete-button">Xóa</button>
                </li>

parentElement của nút <button> chính là <li>.

Cuối cùng: todoItem.remove(); xoá công việc khỏi giao diện

7. Hoàn thiện file JavaScript

Sau khi thực hiện các bước trên, file script.js sẽ có đầy đủ chức năng.

        
            const todoInput = document.getElementById("todoInput");
            const addButton = document.getElementById("addButton");
            const todoList = document.getElementById("todoList");
        
    
        
            // Thêm công việc
            addButton.addEventListener("click", function () {

                const todoText = todoInput.value.trim();

                // Kiểm tra ô nhập
                if (todoText === "") {
                    alert("Vui lòng nhập công việc!");
                    return;
                }

                // Tạo phần tử li
                const todoItem = document.createElement("li");

                todoItem.classList.add("todo-item");

                // Tạo nội dung công việc
                todoItem.innerHTML = 
                `
                    <span>${todoText}</span>
                    <button class="delete-button">Xóa</button>
                `;

                // Thêm công việc vào danh sách
                todoList.appendChild(todoItem);

                // Xóa nội dung ô nhập
                todoInput.value = "";
            });

            // Xóa công việc
            todoList.addEventListener("click", function (event) {

                if (event.target.classList.contains("delete-button")) {

                    const todoItem = event.target.parentElement;

                    todoItem.remove();
                }
            });

Giải thích

Đến đây, JavaScript đã xử lý được toàn bộ 3 yêu cầu của ứng dụng:

        | Chức năng          | Cách thực hiện                      |
        | ------------------ | ----------------------------------- |
        | Nhập công việc     | `input`                             |
        | Thêm công việc     | `createElement()` + `appendChild()` |
        | Hiển thị danh sách | Tạo các phần tử <li>                |
        | Xóa công việc      | `remove()`                          |

8. Chạy thử ứng dụng

Sau khi hoàn thành 3 file:

        todo-list/
        │
        ├── index.html
        ├── style.css
        └── script.js

hãy mở file: index.html bằng trình duyệt. Bạn sẽ nhìn thấy giao diện Todo List. Thử nhập: Học HTML sau đó nhấn Thêm.

Tiếp tục nhập: Học CSS và: Học JavaScript Danh sách sẽ hiển thị:

        Học HTML       Xóa
        Học CSS        Xóa
        Học JavaScript Xóa

Khi nhấn nút Xóa, công việc tương ứng sẽ được loại bỏ khỏi danh sách.

9. Luồng hoạt động của ứng dụng

Có thể hình dung cách hoạt động của Todo List như sau:

        Người dùng nhập công việc
            ↓
        Nhấn nút "Thêm"
            ↓
        JavaScript lấy nội dung input
            ↓
        Kiểm tra nội dung
            ↓
        Tạo phần tử <li>
            ↓
        Đưa <li> vào danh sách
            ↓
        Hiển thị công việc

Đối với chức năng xóa:

        Người dùng nhấn Xóa
                ↓
        JavaScript xác định nút được nhấn
                ↓
        Tìm phần tử <li> tương ứng
                ↓
        remove()
                ↓
        Công việc bị xóa khỏi giao diện

10. Tổng kết

Qua bài hướng dẫn này, chúng ta đã xây dựng được một ứng dụng Todo List đơn giản bằng HTML, CSS và JavaScript. Ứng dụng có ba chức năng chính:

  • Thêm công việc
  • Hiển thị danh sách công việc
  • Xóa công việc

Quan trọng hơn, qua project nhỏ này chúng ta đã làm quen với nhiều kiến thức JavaScript cơ bản như:

  • getElementById()
  • addEventListener()
  • value
  • rim()
  • createElement()
  • classList
  • innerHTML
  • appendChild()
  • parentElement
  • remove()

Đây là nền tảng rất quan trọng trước khi chuyển sang những ứng dụng JavaScript lớn hơn.
